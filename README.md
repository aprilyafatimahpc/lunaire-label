# Lunaire Label

## Tentang Proyek
**Lunaire Label** adalah platform e-commerce yang dikembangkan untuk kebutuhan katalog produk fashion dengan estetika vintage dan elegan. Proyek ini dibangun menggunakan framework Laravel untuk memberikan pengalaman manajemen data yang efisien dan performa yang stabil.

## Teknologi yang Digunakan
- **Framework:** Laravel
- **Bahasa:** PHP, JavaScript
- **Database:** MySQL
- **Web Server:** Apache (via XAMPP)

## Persyaratan Sistem
Pastikan laptop/komputer kamu sudah terpasang perangkat lunak berikut:
- [PHP](https://www.php.net/) (sesuai versi Laravel yang digunakan)
- [Composer](https://getcomposer.org/)
- [Node.js & npm](https://nodejs.org/)
- XAMPP (untuk MySQL dan Apache)
